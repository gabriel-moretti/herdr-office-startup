# Security

Mods execute trusted code with broad user access. World must not run subprocesses or network; Git has a strict query allowlist and never handles tokens itself. No credentials, private terminal screenshots or session files in public issues.

Before the first release, the maintainer must enable/configure GitHub private vulnerability reporting or another verified private contact channel. If private reporting is unavailable, ask the maintainer through an existing trusted channel for a private route; do not disclose exploit details publicly. No unverified email/contact address is invented here. Security support versions and response policy will be declared with actual releases, not promised by this starter.
