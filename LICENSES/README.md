# Upstream license texts

The root Apache text covers original code/tooling. Art/asset full CC BY text is separate. No upstream implementation is included yet. When importing modules, add their actual MIT/ISC/Apache text files here (including exact copyright lines), carry applicable NOTICE, and update THIRD_PARTY_NOTICES with source/destination paths + full SHA. Do not populate this directory with invented ownership text. See [LICENSING](../docs/LICENSING.md).
